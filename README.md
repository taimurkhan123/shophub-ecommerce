# 🛍️ ShopHub – React E-Commerce Store

A modern, responsive e-commerce frontend built with React. It fetches products from an API and includes Home, About, Products, Product Details, Cart, and a custom 404 Not Found page.

## ✨ Features

- 🏠 Home, About, Products, Product Detail, Cart & 404 pages
- 🔌 API-based product fetching
- ⏳ Beautiful loading state while fetching data
- 📱 Fully responsive design
- 🛒 Add to Cart button on Product Detail page
- 🔢 Cart counter in navbar updates instantly (1, 2, 3...)
- 📄 View all added items on the Cart page
- 🎨 Clean UI and beautiful footer
- 🚫 Custom Not Found page for invalid routes

## 🛠️ Tech Stack

- React
- React Router DOM
- Context API (Cart State)
- Tailwind CSS
- Fetch API
